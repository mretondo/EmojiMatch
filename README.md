# EmojiMatch
This is a simple Concentration style game. I created it as a tool to learn Swift and SwiftUI. It's a fun distraction game when waiting in long lines.

1. Pick an Emoji Theme.
2. Tap on two cards to revile the emoji on the underside of card. If cards match you get 1 point. If cards don't match and you've seen the second card before so you know it's not a match you lose 1 point, you also can lose 2 points. You can't touch more than two cards at a time. You have to wait for animations to complete before touching new card.
3. Easy Scoring mode doesn't go below 0 and only penalies 1 point. This is to not discourage young kids or people with disabilities.
4. You post your score by tapping the Score icon in the bottom tab bar
5. The game uses the new Leaderboard "High Score - With Penalties_V1"
6. You can create your own Theame game by pressing the + button. You then can type any character from the keyboard (minimum of 10). Each time a new game is run a random number of 10 characters are picked for that game. Note that Emojis are just characters. You can create a game with all uppercase letters for example.

### User privacy policy
This application gathers NO user personal data at all, period! It has not Social Media capability.
